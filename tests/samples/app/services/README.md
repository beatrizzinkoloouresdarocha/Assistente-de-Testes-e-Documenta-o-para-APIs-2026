# 🤖 Assistente de Testes e Documentação para APIs (2026)

Ferramenta CLI desenvolvida em Python que utiliza Inteligência Artificial para gerar testes unitários automatizados para APIs em FastAPI e executar um loop autônomo de autocorreção usando Pytest.

## 🚀 Tecnologias Utilizadas
- **Python 3.12+**
- **Typer** (Interface de Linha de Comando)
- **FastAPI / Pytest** (Validação e Testes)
- **Google Gemini API / OpenAI API** (Motor de IA)
